## What we build

Control Point is a full-stack team management platform for FIRST Tech Challenge teams — everything a team needs across a season, in one app:

- 🤖 **Bruno** — an AI FTC coach that answers build questions, writes Java, and takes action in the app
- 📊 **Predict** — calibrated advancement forecasting (ratings → match model → event simulation)
- 🔍 **Team Stats** — scouting with live event data and OPR breakdowns
- ✅ **Tasks, Attendance, Calendar, Budget, Inventory, Outreach** — the full team operations stack
- 💬 **Communication & Messaging** — email-style threads, team channels, voice rooms
